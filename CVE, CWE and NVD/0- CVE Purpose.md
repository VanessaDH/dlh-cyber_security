# CVE (Common Vulnerabilities and Exposures)

## 1. What is the purpose of CVE?

CVE is a public, standardized list of known cybersecurity vulnerabilities. Each entry gets a unique ID (e.g., CVE-2021-44228) and a short description, so everyone — vendors, researchers, and organizations — refers to the same vulnerability using the same name.

## 2. How does it help with vulnerability management and information sharing?

- **Common language**: A single ID means different tools, teams, and companies don't use conflicting names for the same flaw.
- **Faster tracking**: Security teams can quickly look up a CVE ID to see what it affects and how serious it is.
- **Easier prioritization**: CVEs link to other resources (like the NVD and CVSS scores) that show severity, helping teams decide what to fix first.
- **Better communication**: Vendors, researchers, and the public can share vulnerability info clearly and consistently, speeding up patching and reducing confusion.

In short: CVE makes it possible to identify, discuss, and manage vulnerabilities consistently across the entire cybersecurity community.
